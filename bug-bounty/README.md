# Bug bounty

## Public (commit this)
- `methodology.md`: your checklist for a new target (recon → mapping → testing each bug class)
- `programs-tried.md`: program names and what you learned (**no vulnerability details**)

## Private (never committed)
`private/` is in `.gitignore`. Real findings, notes about targets and draft reports go there.

## Rules
1. Read the scope and rules twice before touching a target
2. Test **only** in-scope assets
3. Never publish a finding until it's fixed **and** the program allows disclosure
4. Use only your own test accounts. Never access other users' real data.
