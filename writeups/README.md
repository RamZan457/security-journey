# Write-ups

One file per lab topic (or per challenge for CTFs). Copy [`_TEMPLATE.md`](_TEMPLATE.md) each time.

- `portswigger/`: e.g. `sql-injection.md`, which can cover several labs from one topic
- `bandit/`: one file per ~5 levels, with the commands you learned. **Don't publish the level passwords.**
- `picoctf/`: one file per challenge
- `ctf/<event-name>/`: challenges you solved in each CTF, written **after the event ends**

**Rule:** explain the *why* (the root cause and the fix), not only the payload. That's what makes a write-up worth reading for a recruiter, and it's how you actually learn.
