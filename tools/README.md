# Tools

Security tools **you** write in Python. Each folder has a spec. Writing the tool yourself is the exercise, so don't copy finished code.

| # | Tool | Week | Teaches |
|---|---|---|---|
| 01 | [login-bot](01-login-bot/) | 2 | HTTP sessions, cookies, CSRF tokens |
| 02 | [port-scanner](02-port-scanner/) | 4 | Sockets, TCP, threads |
| 03 | [jwt-tool](03-jwt-tool/) | 7 | JWT structure, signature attacks |
| 04 | [recon](04-recon/) | 11 | Automating recon tools |

**Only run these against your own machines, labs, or in-scope targets.**

Each tool should have a `main.py`, a `README.md` with usage examples, and a `requirements.txt` if needed.
