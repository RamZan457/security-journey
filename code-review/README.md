# Code review (week 10 and later)

Audit open-source Express, Laravel or Next.js projects for security bugs. Most hackers don't have this skill, and you do, because you read code professionally.

## For each project, create `<project-name>.md` with
- The repo link and the commit hash you reviewed
- A checklist: auth, access control (IDOR), injection (SQL/NoSQL/command), XSS, CSRF, file upload, SSRF, secrets in code, dependencies
- Findings, with file and line references

⚠️ If you find a real vulnerability, **report it privately** to the maintainers first (check their SECURITY.md) before writing about it publicly.
